# Pixel Decomposer · ピクセル分解

[简体中文](README.md) · **日本語** · [English](README.en.md)

スプライトシートの切り分けに困っていませんか？手伝ってくれる人が見つからず、悩んでいませんか？

面倒な切り分け作業は **Pixel Decomposer** にお任せください！ゲーム用のスプライトシートから、キャラクター、アニメーション、背景などの素材を検出して切り出せます。検出・書き出し・ZIPへのまとめを手軽に行え、細部が気になる場合は選択範囲を手動で調整してから書き出せます。

素材を含むプロジェクトファイルを保存・共有すれば、ほかのメンバーが編集を引き継げます。付属の描画ツールで画像を修正したり、必要なフレームを選んだり、自分の画像を読み込んだりして、GIFアニメーションを作ることもできます。

繰り返し作業を減らして、創作にもっと時間を。ぜひお試しください！

**現在のバージョン：V0.1.4** · [ダウンロード](https://github.com/CZTV-28/Pixel-Decomposer/releases/latest)

## 対応環境

現在は **Windows PC** と **Android スマートフォン** に対応しています。Windows用EXEインストーラーとAndroid用APKを配布しています。

iOS、macOS、Linuxにはまだ対応していません。今後の対応を予定していますが、公開時期は未定です。

## 主な機能

- 自動検出、グリッド分割、矩形選択範囲の手動調整。
- 単色背景の透明化。画像の端につながる背景の検出、色の許容差、元画像の復元に対応。
- ピクセル描画、塗りつぶし、スポイト、最大48色のパレット保存・読み込み・書き出し。
- 直線、四角形、楕円、対称描画、選択範囲の移動、コピー・貼り付け、反転・回転。
- 単独で利用できるGIFタイムライン。フレームの複製、並べ替え、0.01秒単位の表示時間設定。
- アニメーション用キャンバスのサイズ指定、パーツレイヤーの合成、キーフレーム補間、手描きの移動経路。
- PNG・ZIP・GIFの書き出しと、素材を含む `.pdec` プロジェクトの保存。

描画ツールは編集画面の上部から開けます。パーツレイヤーはGIFアニメーション用の機能です。描画エディターでは、独立した描画レイヤーはまだ利用できません。

## ローカルで実行

Node.jsとnpmをインストールしてから実行してください。

```sh
npm ci
npm start
```

## ビルド

Windowsインストーラー：`npm run build:win`。

Android：JDK 21とAndroid SDKをインストールし、SDKのパスを設定してください。ローカル環境変数に `PIXEL_DECOMPOSER_KEYSTORE`、`PIXEL_DECOMPOSER_STORE_PASSWORD`、`PIXEL_DECOMPOSER_KEY_ALIAS`、`PIXEL_DECOMPOSER_KEY_PASSWORD` を設定し、`npm run build:apk` を実行します。ご自身の署名証明書を使用してください。配布版の署名秘密鍵は含まれていません。

インストーラーはGitHub Releasesで配布しています。Windowsインストーラーには発行元のコード署名がありません。Android配布版にはリリース証明書で署名しています。

## 検証状況と制限

V0.1.4では直線描画、元に戻す操作、やり直す操作を検証済みです。背景除去とパーツアニメーションの基本操作もElectron上で動作確認しています。Androidのタッチ操作や縦横画面の表示は、より多くの実機での検証が必要です。

依存パッケージと関連素材には、それぞれのライセンスが適用されます。このプロジェクトのソースコードのライセンスは、まだ指定されていません。
